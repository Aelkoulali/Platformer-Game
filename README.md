# 🗂️ Platformer Game 🎮
This Platformer Game is a web-based project built with JavaScript, HTML, and CSS. It lets you create and control a character in a scrolling game world with interactive obstacles and platforms.

The project is designed to be clean and reusable: it follows good game-element organization, uses classes and objects to represent things like the player, platforms, and enemies, and applies inheritance for shared behaviors (e.g., different types of enemies or game entities). It also uses encapsulation to keep each object’s internal data and logic managed through its own methods, making the code easier to extend and maintain.

## ✅ Key Features
- Runs a 2D platformer in the browser with a controllable player character.
- Efficiently designs and organizes game elements (player, platforms, hazards/obstacles).
- Uses reusable, modular code to make it easier to add new levels or entities.
- Object-Oriented structure: 
    - Classes & objects for game entities
    - Inheritance for shared behavior across similar entities
    - Encapsulation to protect each entity’s internal state
- Smooth interaction and game loop behavior (update/render cycle).

## 🛠️ Tech Stack
- HTML
- CSS
- JavaScript: 
   - Core game logic and rendering
   - OOP concepts: classes, objects, inheritance, encapsulation

## ▶️ How to Run
1. Open `index.html` in your browser.
